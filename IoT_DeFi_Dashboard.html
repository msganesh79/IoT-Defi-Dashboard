Z-Score Anomaly Detection
Z-Score measures how many standard deviations a node's reading is from the group mean. Any node with Z > 2.0 is flagged as compromised and excluded from aggregation before blockchain write.
# Formula Z = |value − mean| / std_dev # Threshold flag_node if Z > 2.0 # Attack example: vals=[25,25,500] mean = 183.3°C, std = 223.1 Z_node3 = |500−183.3|/223.1 = 14.38 >> 2.0 → EXCLUDED

How to connect real ESP32 nodes to this system
1
Start MQTT broker on your laptop
Open a terminal and start Mosquitto. This is the message router your ESP32s will connect to.
mosquitto -v
If it says "address already in use", the broker is already running as a Windows service — that is fine, skip this step.
2
Find your laptop's IP address
Your ESP32s need your laptop's local WiFi IP to connect.
Windows: ipconfig → look for IPv4 Address Mac/Linux: ifconfig | grep "inet "
Copy the IP — it looks like 192.168.1.xxx. Paste it into the Settings page below.
3
Update ESP32 .ino files with your WiFi details
Open each .ino file in Arduino IDE and change these 3 lines:
const char* WIFI_SSID = "YourWiFiName"; const char* WIFI_PASSWORD = "YourPassword"; const char* MQTT_BROKER = "192.168.1.xxx"; // your laptop IP
4
Flash each ESP32 using Arduino IDE
Connect ESP32 via USB. Select board: ESP32 Dev Module. Select correct COM port. Click Upload. If upload stalls, hold the BOOT button on ESP32 during upload.
Node 1 → esp32_node1.ino Node 2 → esp32_node2.ino Node 3 → esp32_node3_attacker.ino
5
Start oracle.py in terminal
This is the Python script that subscribes to MQTT and sends validated data to blockchain.
cd Downloads\iot-defi-project python oracle.py
You should see: ✅ Web3 connected and ✅ MQTT connected
6
Power on all 3 ESP32 boards
Plug all 3 ESP32s into USB or phone chargers. They will auto-connect to WiFi and start publishing sensor data every 5 seconds. Watch oracle.py terminal — you will see messages arriving: 📡 Received from node_1: 26.4°C

Common errors and fixes
ESP32 not connecting to WiFi
Check WIFI_SSID and WIFI_PASSWORD are correct. ESP32 only supports 2.4GHz networks, not 5GHz.
MQTT connection refused
Make sure mosquitto is running. Add "listener 1883" and "allow_anonymous true" to mosquitto.conf if needed.
Upload failed — Write timeout
Hold BOOT button on ESP32 during upload. Try lowering upload speed to 115200 in Tools menu.
DHT22 reading -999 or NaN
Check 10kΩ pull-up resistor between VCC and DATA pins. Without it sensor will not work.
